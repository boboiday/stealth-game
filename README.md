The Quiet Gallery — a complete original top-down stealth game that runs offline in a desktop browser from static files. You are Wren, night archivist of the Emberwick Museum: recover the three relic seals in each gallery and slip out the service exit — unseen.

Guards patrol with vision cones that bend around walls and cover. Suspicion rises while you are seen (faster up close, slower while sneaking or in shadow) and falls when you break line of sight, so a near miss is recoverable. Footsteps carry: guards hear you and come to look. Three galleries, three lives, a ghost bonus for never being spotted.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Move with WASD / arrow keys, or click the floor. Hold SHIFT to sneak. P pauses, M mutes, Space starts.

## Hand it in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
